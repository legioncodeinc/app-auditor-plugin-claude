# Support

## Installation and usage help

Start with the [README quick start](README.md#quick-start), then run:

```text
/webapp-capture doctor
```

The doctor reports missing local requirements and their fixes. The plugin README also includes common runtime fixes in [Troubleshooting](plugins/webapp-capture/README.md#troubleshooting).

## Report a bug

Open a [bug report](https://github.com/legioncodeinc/app-auditor-plugin-claude/issues/new?template=bug_report.yml) with the plugin and Claude runtime versions, operating system, command and route, reproduction steps, expected and actual behavior, and sanitized logs.

Remove credentials, cookies, saved browser state, customer data, private URLs, and private screenshots before posting. Security vulnerabilities must not be reported in a public issue. See [SECURITY.md](SECURITY.md).

## Request a feature

Open a [feature request](https://github.com/legioncodeinc/app-auditor-plugin-claude/issues/new?template=feature_request.yml) describing the problem, desired outcome, use case, and alternatives you considered.
