# Security Policy

## Supported versions

Security fixes are prepared for the latest published release.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not open a public issue containing vulnerability details, credentials, browser session state, customer data, private URLs, or private screenshots.

GitHub private vulnerability reporting is the intended private route for this repository, but it is not enabled yet. Until the repository owner enables it under **Settings → Security → Code security and analysis → Private vulnerability reporting**, there is no verified private reporting destination. Please retain the report and do not disclose sensitive details publicly.

This project does not promise a fixed response or remediation time. Reports will be evaluated against the supported release and the plugin's documented safety boundaries.
